# Translation Glossary — Spanish (es)

Use natural, concise Spanish and informal singular instructions (tú). Preserve established good wording; sentence case is preferred. Product names, protocol identifiers, units and keyboard key legends remain recognizable.

## Formatting

Preserve positional arguments, `${…}` interpolation, Markdown links/backticks and the word joiner before literal percentages. Keep technical identifiers such as `LUT_3D_SIZE`, CUBE, Rec. 2100 PQ, Display P3 and SF Symbol names unchanged. Identical source/Spanish values are intentional for shared words, product/protocol names, units and machine values.

## Retained terms

- HiDPI, LoDPI, HDR, SDR, XDR, DDC, EDID, DisplayID, HDMI-CEC, Metal: Technical identifiers.
- Night Shift / True Tone / Tri-Screen: Apple feature names and Monduo product setup name.
