# Translation Glossary — Ukrainian (uk)

Використовувати звичайний регістр речення, без англійської капіталізації кожного слова.

## Conventions

Зберігати ідентифікатори, URL, комбінації клавіш, позначення кнопок стороннього обладнання та заповнювачі без перекладу.

## Retained terms

BetterDisplay, Apple, macOS, Metal, AirPlay, Sidecar, Night Shift, True Tone, Mission Control, Spaces, Dock, Launchpad, HDMI-CEC, EDID, DisplayID, DDC, HDR, SDR, XDR, HiDPI, LoDPI, PIP, LUT, RGB, YCbCr, API, CLI, HTTP, UUID — зберігати як технічні назви.

Underscan, Downspread, Display Stream Compression (DSC), Apple Built-in XDR Direct — навмисно збережені технічні назви. Photo Effect Chrome/Fade/Instant/Noir/Process/Transfer — назви варіантів фільтра, збережені для впізнаваності.

LG alt — збережена коротка назва альтернативної таблиці входів LG, узгоджена з підказкою.
