# Translation Glossary — Swedish (sv)

Use natural Swedish sentence case and compact UI wording.

## Conventions

Preserve `${...}` interpolation identifiers, printf argument types and positions, URLs, keyboard symbols, units, API names, and code examples. Translate labels inside Markdown while keeping delimiters and link destinations. Machine-facing scaling ratios and encoding identifiers remain unchanged; prose uses Swedish decimal formatting.

Use a space before a percentage sign in Swedish prose; a nonbreaking space keeps the number and sign together.
