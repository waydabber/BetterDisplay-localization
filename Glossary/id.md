# Translation Glossary — Indonesian (id)

Standard Indonesian as used in Indonesia; concise, neutral UI wording. Use Anda only where useful. No grammatical singular/plural variation is needed for counted items.

## Conventions

- Keep product names, protocol and hardware identifiers, URLs/domains, units (nits, bit, mm), HiDPI/LoDPI, HDR/XDR, EDID/DisplayID, GPU, CLI, OSD and keyboard modifier names unchanged. Tri-Screen is a product setup name.
- Terminology is chosen for natural Indonesian usage; only terms actually checked against Apple documentation are attributed to Apple.
- Retain framebuffer, temporal dithering, compositor and overlay in technical contexts. App, default, driver, remote, amplifier, pop-up and technical multiplier notation are familiar technical usage. Use file consistently; streaming, polling, broadcast, unicast, firmware, shell, regex and network magic packet remain technical terms.
- Retain established graphics blend-operation names Color, Difference, Exclusion, Hard Light, Hue, Luminosity, Multiply, Overlay, Saturation, Screen and Soft Light. Screen in this context is not a display. Bloom and gain are technical image-processing terms.
- Retain graphics/filter names Bloom, Gloom, Unsharp Mask, Vibrance, Vignette, and photo preset names Chrome, Fade, Instant, Noir, Process, Transfer. Retain DisplayPort terminology Downspread, Enhanced framing, DSC slice/tile, timing, buffer, payload, bandwidth, dithering and underscan; these identify specific technical operations or structures.
- Shared Indonesian/technical UI words intentionally matching English include Edit, Filter, Gain, Gamma, Horizontal, Internal, Median, Menu, Model, Platform, Preset, Sepia, Transfer, Virtual, Volume, Zoom, Build. Keep standard identifiers and numeric-only strings, product and protocol names, standard color spaces and code examples (including My parameter) unchanged.
- Use the Indonesian decimal comma for ordinary prose, preserving machine-style numeric identifiers and requested multipliers.
