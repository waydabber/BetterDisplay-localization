# Translation Glossary — Polish (pl)

Use natural Polish sentence case. Actions normally use the imperative; grammatical gender and case follow the actual UI subject.

## Conventions

URLs, code, interpolation tokens, device commands, hexadecimal data and service passwords retain their original spelling. Numeric values and unit-only strings can intentionally match English. English protocol labels and product names may also remain when they identify actual device UI options.

Retain established macOS labels and technical distinctions when an imported glossary is broader or ambiguous. In particular, main is not default, dimming is not all software brightness, and offset in display geometry is przesunięcie rather than odstęp. Dictionary infinitives must be adapted to imperative UI actions.
