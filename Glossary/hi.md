# Translation Glossary — Hindi (hi)

Standard Hindi for India. Use Devanagari, concise polite commands (करें/चुनें), familiar technical vocabulary, and international numeric/unit notation.

## Conventions

Leading icon placeholders retain source order. Use positional arguments when Hindi grammar changes argument order. Keyboard shortcut modifiers stay together with nonbreaking spaces.

Invariant count phrases such as “दिन शेष” and “इंस्टॉलेशन पर सक्रिय” work across Hindi counts without extra plural branches. Group exclusivity concerns activation priority, not a merely specific group.

## Retained terms

Retain product names, API/protocol names, units, acronyms, identifiers, commands, URLs, and shortcut glyphs: BetterDisplay, macOS, Apple, DDC, EDID, HDR, SDR, XDR, RGB, USB, HDMI, DisplayPort, HiDPI, UUID, Hz, nits, etc. Retain device firmware setting names (Auto Power Sync, QuickStart+, etc.), Simple Manifest, Tri-Screen, and numeric scaling/chroma/angle notation exactly.

Retain standard compositing blend operation names (Color, Difference, Exclusion, Hard Light, Hue, Luminosity, Multiply, Overlay, Saturation, Screen, Soft Light). They identify technical algorithms; Screen is not a physical display. Translate the shared Blend Mode label. Retain Night Shift, True Tone, Sidecar, Metal and Touch Bar.

Retain named photo presets Chrome, Fade, Instant, Noir, Process and Transfer. Familiar filter names are transliterated (गॉसियन ब्लर, अनशार्प मास्क, विन्येट, आदि). In technical fields retain protocol/format names and their standard expansions, including Display Stream Compression, Extended Display Identification Data, Save Current Settings, Downspread, regex, and CUBE headers. Retain quoted script identifiers such as `My parameter`, app/library/font names, firmware menu names, profile names, paths and URLs. HW remains in compact hardware-boundary badges. Product/version/unit-only entries intentionally remain unchanged.
