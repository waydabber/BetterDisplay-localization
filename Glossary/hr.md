# Translation Glossary — Croatian (hr)

Standard Croatian as used in Croatia. Use concise neutral UI nouns and infinitive action labels; explanatory instructions address the user politely in the plural. Terminology is chosen for natural Croatian technical usage, without claiming verified Apple wording except where cited.

## Conventions

- Retain product names, protocols, identifiers, units and standard abbreviations (BetterDisplay, macOS, Apple, DDC, EDID, HDR, SDR, XDR, HiDPI, LoDPI, RGB, USB, HDMI, DisplayPort, LUT, CUBE, ICC, HTTP, CLI, API). Preserve code, URL and parameter identifiers verbatim.
- Croatian plural categories one/few/other apply when a number governs an inflected noun. Use count-label constructions where natural and avoid assumptions about dynamically formatted object values. For integers, one includes 1, 21, 31 except 11; few includes 2–4 and final 2–4 except 12–14; other covers the remainder. Apply the categories to additional color modes, license installations, remaining days, trial days, bits per sample and LUT assignment counts. The dual-count CUBE error uses count labels to avoid choosing between two independent integer arguments.
- Luminance unit fields use `cd/m²`, exactly equivalent to nits and invariant beside arbitrary formatted numbers. Prose uses nit/nita/nitima as grammatically appropriate. Inch input uses invariant `in`; hardware slider badges retain `HW` for compactness.
- Retain protocol/format names and brands, including Downspread, Simple Manifest (webOS registration mode), Tri-Screen, SF Symbols, Display P3, Rec. 709, Rec. 2100 PQ, MusicCast, Night Shift, True Tone and Sidecar. Retain firmware menu names EZ ADJUST/IN START and device setting names quoted for recognition. `regex`, `CGDirectDisplayID`, `LUT_3D_SIZE`, Base64, UTF-8 and code identifiers are technical vocabulary. Numeric-only labels, ratios, multipliers and placeholder-only compositions remain unchanged. Croatian Model and bit legitimately match English.
