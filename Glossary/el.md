# Translation Glossary — Greek (el)

Modern Greek as used in Greece. Use concise noun phrases in controls and polite plural imperatives in instructions. Display and screen naturally share οθόνη; do not invent a physical/framebuffer distinction in ordinary labels.

## Conventions

- Retain brands, product names, protocols, APIs, codecs, hardware identifiers, units (nits, Hz, mm, bit), acronyms (DDC, EDID, HDR, XDR, HiDPI, LoDPI, GPU), code examples, paths and URLs. Retain dithering as the familiar technical term.
- Standard macOS labels use natural Greek; only the terms identified in References are verified Apple wording. Other specialized choices are contextual Greek choices.
- Retain established filter names Screen (blend mode), Chrome, Process and Transfer (photo presets) to avoid misleading literal meanings. HW is retained only in compact minimum/maximum hardware badges. Downspread, regex, SF Symbol and all firmware setting/service menu names remain recognizable. Retain the literal LG alt column label in input-source help.
- Count-independent unit labels use conventional abbreviations and must work at 1. Use δευτ. in help containing preformatted dynamic durations as well. Greek bit/byte/pixel units are invariant; pure numeric modes, ratios, protocol names, product domains, OK and format-only combinations intentionally remain unchanged.
- Greek cardinal plural categories are one and other; use inflection where a count requires it. Leading-icon counts preserve icon argument 1 and pluralize numeric argument 2. The CUBE count uses an explicit argument-1 substitution; its expected count is at least 8 (dimension cubed), so the expected-count clause stays plural.
