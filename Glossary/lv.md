# Translation Glossary — Latvian (lv)

## Conventions

- Address the user politely; retain healthy existing **jūs/Jūs** usage. Buttons and menu items use infinitive verbs («Saglabāt», «Atcelt», «Lietot») as a project convention; no Apple macOS terminology authority is implied.
- Keep technical identifiers untranslated: **BetterDisplay, Apple, macOS, HiDPI, LoDPI, HDR, SDR, XDR, EDID, DisplayID, DDC, DDC/CI, CLI, DSC, CEC, LUT, OSD, VRR, PWM, P3, sRGB, DCI-P3, Display P3, RGB, YCbCr, 4:2:0, HDCP, USB-C, HDMI, DisplayPort, Thunderbolt, Wi-Fi, Ethernet, Bluetooth, GPU, Intel, Apple Silicon, M1/M2, Sidecar, AirPlay, Night Shift, True Tone, Dock, Spaces, PIP, WOL, IP, MAC, HTTP, TCP, UUID, URL, JSON, XML** and brand/product names.
- Placeholders (`%@`, `%lld`, `%u`, `%1$@` …), `${tokens}`, newlines, links and shortcut symbols (⌥ ⌘ ⇧ ⌃) must be preserved; positional forms may be simplified to `%@` when order is unchanged.
- Use Latvian quotation marks „…”, em dash — with spaces, and … (ellipsis) as in source.
- Percentages: no space before % (100%). For numeric readouts and separate unit fields use invariant symbols: `cd/m²` (same value as nits), `lx`, `s`, `ms`, `B`, `bit`, `″` (inches), `d.` (days), and `×` (repetitions). In prose, inflect the spelled-out unit normally. Keep `Hz` unchanged.
- For hardware and screen-content contexts, use **display** = displejs, **screen** = ekrāns, **monitor** = monitors. Translate other senses contextually, for example printing screen = rastrs.

- Count-dependent strings use Latvian `zero`, `one`, and `other` categories where agreement varies. Choose noun and predicate forms for the sentence: the `zero` category does not automatically require a genitive. Standalone unit labels are distinct from inflected nouns in sentences.
