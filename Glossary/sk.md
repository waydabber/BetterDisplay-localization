# Translation Glossary — Slovak (sk)

Standard Slovak as used in Slovakia. Use a concise neutral UI register, infinitives for actions and polite plural imperatives in instructions.

## Conventions

Slovak plural agreement: `one` for 1; `few` for integer 2–4; `other` for 0 and 5+; `many` for fractional values where applicable. Numeric arguments supplied as formatted text use invariant constructions or units where necessary. Current count-sensitive numeric inputs are integers, so `many` is unreachable but remains part of the full category set. Icon-leading plural substitutions explicitly select the second argument. The CUBE error pluralizes actual entries and presents the expected count as an invariant label.

Units beside variable values use invariant labels such as mm, s, ms, in, lux and nit. Numeric multipliers retain source notation. Word-joined percentages and shortcut glyph ordering are preserved.

## Retained terms

Retain brands, protocol/API names, abbreviations (HDR, SDR, XDR, DDC, EDID, HiDPI, LoDPI, GPU), units, machine identifiers, sample code, URLs and named product setups such as Tri-Screen.

Official firmware/protocol setting names remain identifiable: Simple Manifest, EZ ADJUST, IN START, QuickStart+, Always Ready, Turn on via Wi-Fi, Networked Standby, Auto Power Sync, Anynet+, Downspread. Retain standardized color names (Display P3, sRGB, Rec. 709, Rec. 2100 PQ), SF Symbol identifiers, code examples and API names. English-identical wording is intentional for these terms, format-only combinations, numeric notation, and words also natural in Slovak (Menu, Model, Stream, OK).
