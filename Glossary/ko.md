# Translation Glossary — Korean (ko)

Use concise noun phrases for controls and polite 합니다/하세요 sentences for explanations.

## Conventions

Use **을(를)** for an object particle after a runtime value whose final sound is unknown. Preserve Markdown delimiters and interpolation tokens. Positional format specifiers are required when Korean sentence order reverses runtime arguments.

## Retained terms

Keep BetterDisplay, Apple, macOS, Metal, DisplayLink, DisplayPort, HDMI, DDC, EDID, DisplayID, HDR, XDR, SDR, HiDPI, LoDPI, LUT, PIP, OSD, GPU, CPU, UUID and CLI intact. Preserve URLs, command tokens and keyboard labels (Command, Option). Numeric formats, chroma ratios and units may remain unchanged. Vendor-specific on-device option names may remain English for identification.

Downspread, Display Stream Compression (DSC), LG alt, Rec. 709, Rec. 2100 PQ, sRGB, Display P3, YCbCr, n/a, vendor/model names, numeric-only values, URLs and machine identifiers are intentionally retained in English where present.
