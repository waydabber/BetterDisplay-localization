# Translation Glossary — Catalan (ca)

Standard Catalan as used in Catalonia. Concise action labels use the imperative; explanatory instructions use polite plural forms (feu, manteniu, podeu).

## Conventions

- app, framebuffer, GPU, CPU, HDR, SDR, XDR, HiDPI, LoDPI, NTSC, DDC, VCP, EDID, UUID and protocol identifiers remain technical identifiers. Product and model names, service names, URLs, code, units, literal numeric passwords and product setup name Tri-Screen remain unchanged.
- Firmware menu names and option labels (EZ ADJUST, IN START, QuickStart+, Always Ready, Auto Power Sync, etc.) remain recognizable. Example code identifier `My parameter` remains exact. Zoom is conventional Catalan UI terminology.
- Keep shortcut glyphs and physical key order.
- Source-identical Catalan words are intentional: Variable, bit, bytes, Contrast, Control, Dimensions, Experimental, Gamma, Model, No, Original, Vertical, Virtual, Visible. Uppercase forms and technical/numeric labels follow the same rule.
- Retain OSD, DSC, CUBE, LUT, LUT_3D_SIZE, Rec. 709, Rec. 2100 PQ, Display P3, sRGB, RGB, YCbCr, HDMI-CEC, WOL/WoWLAN, S/PDIF, I2C, SF Symbols, CGDirectDisplayID, regex, Downspread and Underscan. Underscan means inward image scaling to fit the visible area.
- Catalan cardinal categories are one, many and other. Use the linking preposition de/d’ in the million category. The CUBE actual/expected count diagnostic uses invariant “nombre d’entrades … nombre esperat” wording so both independent numeric arguments work for any count. Numbered slots, block/group IDs, manufacture dates, error codes and hardware depth readouts are identifiers or fixed technical units rather than grammatical count messages.
- Only the terms identified in References are attributed to Apple; other specialized BetterDisplay terms are independent choices.
