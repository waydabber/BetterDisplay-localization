# Translation Glossary — Norwegian Bokmål (nb)

Use concise, natural Bokmål.

## Conventions

Use a hyphen when joining acronyms to Norwegian words: **DDC-kontroll**, **HDR-verdier**, **SDR-innholdsområde**, **HDR-LUT-støtte**. Inflect the standalone lookup table as **LUT-en** where definite.

Preserve URLs, code identifiers, interpolation, keyboard symbols and positional arguments. Do not translate visible URL paths.

## Retained terms

Retain Bloom, Downspread, Underscan, named Photo Effect presets (Chrome, Fade, Instant, Noir, Process, Transfer), LG firmware commands EZ ADJUST and IN START, LG alt, technical color-space names, protocol identifiers, product names, units and numeric scale labels. Identical words such as Gamma, Median, Original, Type and Zoom are also valid Bokmål.
