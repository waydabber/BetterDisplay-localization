# Translation Glossary — Romanian (ro)

Terminology for Romanian UI labels and BetterDisplay features.

## Conventions

- Keep BetterDisplay, macOS, HDR, SDR, HiDPI, LoDPI, EDID, DisplayID, DDC, GPU and named protocols unchanged.
- Keep keyboard names Command, Option, Shift and Control recognizable with their symbols.
- Keep CUBE, LUT, LUT_3D_SIZE, Rec. 709, Rec. 2100 PQ, Display P3, sRGB, RGB, YCbCr, SF Symbols, face.smiling, Sidecar, Night Shift, True Tone, HDMI-CEC, WOL/WoWLAN and protocol/model identifiers unchanged.
- Intentionally retained technical/filter names include Downspread, Notch, X-Ray, Screen (blend mode), Bloom, Chrome, Noir, Process and Transfer. Romanian cognates such as Contrast, Control, Model, Original, Virtual, Vertical, Experimental and Zoom legitimately match English.
- Keep literal URLs, interpolation names, format specifiers and numeric technical values unchanged. Romanian text uses comma-below ș/ț; remove accidental zero-width and draft artifacts.
- Shortcut summaries: prefer pentru followed by an unchanged display/feature parameter, avoiding lui or bare genitive articles before arbitrary names.
- SF Symbols icon fields identify the symbol used for a custom icon; SF Symbols is not the name of the app.
- Streaming is an accepted technical borrowing in explanatory text. Retain standby for external-device power states.
