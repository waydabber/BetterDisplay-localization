# Translation Glossary — Slovenian (sl)

Use clear, professional Slovenian. Use polite plural imperatives in explanatory text and compact singular commands in action labels.

## Conventions

Preserve literal integration identifiers (including `My parameter`, `${...}`, `LUT_3D_SIZE`, `face.smiling`), keyboard symbols and URL targets. Machine input uses a decimal point even though Slovenian display formatting commonly uses a comma. Numeric counts that vary at runtime can use a colon construction to avoid incorrect fixed plural forms.

## Retained terms

Preserve product names, API names, protocol identifiers, URLs, CLI arguments, units and technical acronyms such as BetterDisplay, macOS, LG webOS, DDC, EDID, HDR, SDR, HiDPI and LoDPI.

Retain Night Shift, True Tone, Sidecar, Finder, Dock, Metal and other product/API names. Retain standard technical labels such as Downspread, Underscan, Display P3, Rec. 709, Rec. 2100 PQ and the controller identifier Apple Built-in XDR Direct. Named photo presets Chrome, Noir, Instant, Process and Transfer may remain English. Identical source/target values such as Model, bit, Filter…, OK and technical units/identifiers are intentional.
