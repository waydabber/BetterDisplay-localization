# Translation Glossary — Bulgarian (bg)

Standard Bulgarian. Neutral, concise UI labels; polite plural imperatives in instructions.

## Conventions

- Retain product names, protocol identifiers (DDC, EDID, DisplayID, HDMI-CEC), HDR/SDR/XDR, HiDPI/LoDPI, RGB, Metal, API/CLI, UUID, units and numeric codes. Keep modifier key names and glyphs (⌥ Option, ⌘ Command) for recognizability.
- Retain firmware menu names (EZ ADJUST, IN START), Downspread, underscan, SF Symbol identifiers, and macOS settings quoted as English firmware/system names when this improves recognizability. Inch uses invariant international unit in.
- Bulgarian plurals use one/other. Explicit branches cover countdown days, extra color-mode counts, bits per sample, and LUT assignment counts. Count-label constructions avoid agreement problems where two numbers occur together.
- Retained English-only entries are product/brand names, format/API/protocol identifiers, units, numeric notation, domain links, dynamic-placeholder compositions, and compact technical labels (including regex, OK, Sidecar UUID). Photo presets Chrome, Noir, Process and Transfer retain their recognizable preset names; descriptive effects are translated.
- Fixed unit labels beside editable numbers use invariant forms to avoid singular/count-form errors at 1; ordinary prose retains inflected Bulgarian unit names. Numeric luminance readouts use `nit` consistently.
- Translate UI labels such as HDR Filter Pipeline and Exposure inside backticks as well.
- PIP can stand for the enclosing Picture in Picture feature.
